Vite & TanStack Start Dev Server

You are currently viewing this folder through a static HTTP server (like VS Code Live Server on port 5502). Because AgriConnect is a fullstack Vite + TypeScript + React Router application, it needs the Vite dev server to compile and run.

# Run this in your terminal to start the live app:
npm run dev  (or: bun run dev / npx vite dev)

Once started, open the Vite server URL displayed in your terminal (typically http://localhost:3000 or http://localhost:5173).
